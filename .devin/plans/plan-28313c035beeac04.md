- **`src/constants/combat/combat/global.ts`**: `RESPONSE_COUNTER_INI = 2` (responder seizes tempo vs a committed attack), `RESPONSE_WASTED_INI_MULT = 0` (Response vs non-Decise attack is wasted). The decise edge itself reuses the existing `decBonus` field — no new magnitude needed.
- **`src/engine/combat/resolution/tacticCounter.ts`** (new): `resolveTacticCounters(tactA, tactD, offModsA, offModsD, defModsA, defModsD)` → `{ tacticIniA, tacticIniD, defIniBonusA, defIniBonusD }` implementing the canon RPS:
  - `tacticIniX = offModsX.decBonus` when `offTactic === 'Decisiveness'` AND opponent's `defTactic !== 'Responsiveness'`; else 0. (Decise's canon advantage = a live first-strike edge vs everything except Response.)
  - `defIniBonusX = iniBonus + RESPONSE_COUNTER_INI` when `defTactic === 'Responsiveness'` and the OPPONENT runs Decisiveness (hard counter); `= iniBonus * RESPONSE_WASTED_INI_MULT` when opponent runs non-Decise (canon: any non-Decise tactic has the advantage over Response); unchanged otherwise.
- **`exchangePrep.ts`**: call the helper inside `resolveTacticsAndBias`; return the four values on `ExchangeSetup`.
- **`initiativePhase.ts` + `resolution.ts`**: thread `tacticIniA/tacticIniD` + adjusted `defIniBonus` into `resolveInitiativePhase`/`sumInitiative` (added alongside `defMods.iniBonus` — or replace iniBonus with the adjusted scalar; pick the cleaner signature at edit time, both are internal).
