# Arena 93 Learn System + Loser Turnaround Port

Port the Arena-93 "skill learning" articles into a real mechanic — per-fight weighted-pool learns gated by WT with a hidden favorite learn, learn discovery/deduction, a player-facing loser-turnaround advisor plus directed AI tinkering, a 4th weapon-chart column and canon crit narration — built strictly test-first, additive, deterministic, and re-ratcheting world balance afterward.

## Summary

The Arena-93 newsletters in scope cover how warriors actually improve: per-fight skill learns drawn from a style-priority pool (Pagan's priority-learning chart), the hidden "favorite learn" third affinity, skills-vs-stats training tradeoffs, weapon charting (including "extra value" crit damages and per-weapon crit lines), and managerial doctrine for rehabilitating a losing warrior. The engine already has favorite weapon/rhythm, charting, canon challenge/avoid targeting, ε-greedy strategy tinkering, and debrief factors — but **no learn mechanic at all** (progression is XP→attributes only, and `skillLearnLine` narration is dead code). This plan adds the missing learn system end-to-end, plus the turnaround/diagnostic layer, for both the player and rival AI.

User-confirmed scope: **full learn system, generous canon-flavored caps, turnaround for players AND AI, both crit content pieces**. Backwards compatibility is explicitly NOT a constraint; additive-optional schema fields are still used — they are the cleaner design here, not a compat shim.

- ⚠️ **Insight tokens are two systems.** (a) `InsightToken` objects — `InsightTokenType` z.enum `['Weapon','Rhythm','Style','Attribute','Tactic','Trait']` (`types/state/game.ts:380`, `warriorSchemas.ts:411`) granted by offseason events and consumed in `rosterSlice/actions.ts:applyInsightToken` — 'Learn' → `favorites.discovered.learn = true` (note: its `draft.favorites` fallback at `:24-28` needs the new `learn`/`learnHints` fields too). - ⚠️ **Newsletter spam risk.** Existing hint items fire for every warrior including rivals; a learn item per bout per warrior floods the gazette. - ⚠️ **Transcript learn lines are drawn-free.** Build them deterministically from `post.learnsA/D` (`{minute: outcome.minutes, text, emphasis}` on `outcome.log`) — no archive draw, zero extra stream consumption for the line itself; the learn roll's draws happen regardless. `skillLearnLine` stays available but isn't required.

## Design decisions (validated)

- **`learnedSkills: Partial<Record<keyof BaseSkills, number>>`** on `Warrior` — additive like `skillDrills`, summed in `skillAddends` (`fighterState.ts`), always routed as the whole accumulated map (partial-spread replaces the field — same as `favorites`).
- **Learn roll in `handleProgressions`**, inside the existing per-warrior loop, ordered: XP A → XP D → {chart merge → **learn roll** → discovery} A → {...} D. Learns roll *before* `checkDiscovery` so `context.learnedFavorite` can fire the favorite-learn epiphany (symmetry-analog roll).
- **Favorite learn derived**: `favoriteLearnOf(w) = SKILL_KEYS[hashStr(w.id) % 6]` — pure, deterministic, no creation-stream draw, works for every warrior.
- **Budget**: `LEARN_ATTEMPTS = 6`, each succeeds at `p = WT × LEARN_WT_FACTOR` (0.04 → WT5≈1.2, WT10≈2.4, WT15≈3.6, WT21≈5.0/fight). Pool weight = own-style priority + opponent-style priority (+`LEARN_FAVORITE_WEIGHT=6`). Caps `LEARN_PER_SKILL_CAP = 6`, `LEARN_CAREER_CAP = 24`. Dead-side skip as validated.
- **Pagan priority table** (weights 6..1): AB→ATT,RIP,DEF,PAR,DEC,INI · BA→ATT,INI,DEC,PAR,RIP,DEF · LU→INI,DEF,RIP,ATT,DEC,PAR · PL→INI,PAR,ATT,DEF,DEC,RIP · PS→PAR,DEC,INI,ATT,DEF,RIP · PR→RIP,PAR,ATT,DEF,INI,DEC · ST→DEC,ATT,INI,RIP,PAR,DEF · SL→INI,ATT,RIP,DEC,PAR,DEF · WS→ATT,INI,PAR,DEF,DEC,RIP · TP→PAR,DEF,RIP,ATT,DEC,INI. Weighted draws iterate `SKILL_KEYS` declaration order via `rng.rollWeighted` — never object key order.
- **Fixture harness unaffected** — learns are post-bout meta outside `simulateFight`; only the world surface shifts → re-ratchet lever is `STYLE_SKILL_FLOORS` (world-only), `STYLE_PENALTIES` only if a style's pool systematically out-learns others. `MATCHUP_MATRIX` untouched.

## Risks

- **World balance shift** (~24 flat skill/career at generous caps; WT-gating widens rookie-veteran gaps — canon-consistent): constants centralized; Phase 8 ratchet is mandatory.
- **In-bout RNG stream churn only**: new draws are scoped to each bout's `SeededRNG(boutSeed)` — no cross-bout leakage; invariants to hold are narrated===headless and shard===in-line parity.
- **Bracket-path tournaments get no learns** — same coverage as XP today (pre-existing gap; call out in docs, don't silently fix).
- **Caps interplay** (learns + drills + luckfactor + mastery ≈ +13 on one skill): world harness verifies.
- **Pool-driven style drift** (LU learns INI/DEF, TP PAR/DEF): absorbed in floors/penalties, never the matrix.
