# Port the Arena-93 Wall of Steel article corpus into Stable Lords

Port the five Wall of Steel Noblish Island articles (Eli, Assur's Bash Bros, Dante Killatroll, She-Puppy, Wasted Wastes) across every canon surface — fighter concepts, strategy presets, design-review doctrine, AI plan doctrine, canon targeting, validator warnings, favorites, docs — plus two combat changes (high endurance burn + the OE=KD harmony rumor) with a mandatory STYLE_PENALTIES re-ratchet, mirroring the ST/PL/PS port in commit 6661dd85. Tests are authored first (RED), then implementation (GREEN), then re-ratchet + full-suite verification.

## Objective

Incorporate the pasted Duel2 Arena-93 Wall of Steel ("Waste") newsletter articles as canon game data/mechanics, following the pattern of commit `6661dd85` ("port Arena-93 striker/parry-lunge/parry-strike articles + mechanics"). WS currently has generic content only: two spec-derived presets, two fighter concepts, a compendium entry — but **no** canon notes in `designReview.ts`, no `applyStyleDoctrine` branch, no `canonTargeting` row, and two mechanics that contradict the corpus.

## Canon facts (source of truth for values)

- **Stats:** ST ≥9 via *wielding the scimitar* (real req: ST9/WT11/DF11; 11 ST adds BS/QS, 13 the GA), CN flexible (low-con viable if run hot; Dante wants ST+CN ≥21), SZ ~7–14 (tiny hits soft; big pays DEF/PAR skill points + endurance), WT 15+ (learning crawls below), WL ≥15 mandatory (17/21 preferred; Dante allows 11 non-ADM), SP is a luxury (Assur adds 0; Eli runs 3), DF ≥11.
- **Strategy:** open hot (Eli 10-10-6, She-Puppy 9-6-6, Dante 6-4-6), taper to high-OE/low-AL; KD ≤6 normal (7+ only as a life-saver); run offensively while young; desperation 2-6-2 + Parry; attack arms; protect AM→HE.
- **Matchups:** challenge any style except lungers; end-game AB/LU are OP vs walls; slow down vs scum.
- **Mechanics:** high endurance burn "similar to lungers" (Assur); INI/PAR/ATT favored learns, DEF weak (already encoded); OE=KD bonus rumor (She-Puppy, unconfirmed — implemented as discoverable depth mechanic).

## Acceptance criteria

- All Phase-0 specs green post-implementation; no other test regressions.
- `reviewWarriorDesign(Bender, WS)` produces no `warn` items; `reviewWarriorDesign` on a `WL<15`/`DF<11`/unwieldable-scimitar wall produces the canon warnings.

## Risks / considerations

- **Re-ratchet iteration cost** — +0.10 enduranceMult is a real late-fight nerf on a style whose tempo already peaks late; may need several lab passes on the WS penalty row. `STYLE_SKILL_FLOORS` untouched (world lever; fixture-invisible).
- **Determinism** — no new RNG consumes (harmony/mult are arithmetic; favorites range alters values, not draw counts), but outcomes shift → seeded tests may need re-baselining, same class as 6661dd85.
- **`fights<8` boundary** — canon says "while young" without a number; constant is tunable and documented.
- **Ordering dependency** — `applyStyleDoctrine` must remain the last plan-shaping step (`index.ts:110`) or `getStyleSuitabilityBias`'s `{oe:−1,al:+2}` re-damps the young-wall floor.
- **Anti-power-creep** — harmony stays +1 PAR; if the lab shows WS strong post-port, re-ratchet absorbs it rather than shrinking the mechanic.
