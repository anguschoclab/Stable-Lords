# Megaplan: The Almanac — all-time record boards for the History page (validated)

Add an "Almanac" tab to /world/history (HallOfFame page) rendering every hall-of-fame/all-time/top-N record the game can honestly measure from live state + archival data — and repair five dead/broken record systems plus one newly discovered pipeline bug (impact-map clobber that drops award effects every year rollover). Strict test-first: all specs written and failing before any implementation.

## Objective

The History page (`/world/history` → `src/pages/HallOfFame`) gains a third tab — **Almanac** — a records book covering every measurable "hall of fame / all-time greats / top-N" category, computed from **live state + archival data** (no new persisted fields; save-compat irrelevant per directive). Alongside, fix the record systems found dead/broken **plus one new bug found during validation**.

## THE RECORD TAXONOMY — everything the Almanac lists and tracks

Uniform row: `{ warriorId?, name, epithet?, stableName?, style?, value, valueLabel, sub?, isPlayer, status }` via `StandingsTable`. Deterministic total order — comparator chains end in id. Pool = `collectAllKnownWarriors` (roster+rivals+graveyard+retired). Stable names via `ensureEntityIndex(state).stableNameById`.

## Fixes (all evidence-verified)

1. **`processSystemicProgression` impact-map clobber (NEW — land first)**: `SystemPass.ts:54-60` — merge `rosterUpdates`/`rivalsUpdates` **entry-by-entry** (`map.set(k, {...prev, ...next})`) across the four sub-impacts instead of object-spread replacement. Without this, Fix 2's fame bump + `warrior.awards` never land on rollover ticks.
2. **Produce `STABLE_OF_YEAR`** in `processHallOfFame`: group `eligible` by `w.stableId`, Σ year-delta wins per stable, argmax (Σ fame tiebreak), **require Σwins > 0**; resolve stableName (`state.player.stableName` / `rivalMap`/entity index); emit `AnnualAward{type:'STABLE_OF_YEAR', stableId, stableName, value=Σwins, reason}` + hofNews — **no `recordAward`** (stable-level; no warrior mutation).
3. **Produce `TOURNAMENT_RANK`** ("most decorated tourney fighter of the year"): Δmedals = `career.medals − snapshot[completedYear].medals` (absent snapshot/medals → 0s); score `3ΔG+2ΔS+ΔB`, `pickBest` w/ fame tiebreak, score>0; emit award `value=score`, `reason` lists ΔG/ΔS/ΔB; `recordAward` fameBonus 25 + hofNews.
4. **Render `state.hallOfFame`** via §6 #32–33.
5. **Fix Gazette `BestByStyle`**: styles = `Object.values(FightingStyle)` (`GazetteLeaderboards.tsx:161`).
6. **All-Time Greats permanent + honest caption**: render unconditionally; replace hardcoded "First Annual Inductions at Week 52" caption (misleading post-Year-1) with a real derived label.
7. **`AwardIcon`**: add `TOURNAMENT_RANK` → `Medal` case (currently default Star).
