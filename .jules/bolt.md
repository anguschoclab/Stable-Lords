## 2024-03-24 - React Component State Selectors
**Learning:** Selecting large state slices from Zustand (e.g., `s.roster`, `s.graveyard`) directly in heavily-used components using `useShallow` causes excessive re-renders, as any change to those slices triggers a render even if the specific data the component needs hasn't changed. The memory notes explicitly state: "To prevent excessive re-renders in React components connected to the Zustand useGameStore (especially heavily-used components like entity links), avoid using useShallow to select large state slices (e.g., roster, graveyard). Instead, use targeted selectors that return computed primitive values (e.g., a resolved ID) and wrap the component in React.memo. Passing the raw store state directly to pure functions (e.g., findWarrior) allows them to correctly use their WeakMap cache."
**Action:** In `src/components/EntityLink.tsx`, replace `useShallow` with targeted selectors that only extract the resolved ID, and wrap the component in `React.memo`. Use `useGameStore.getState()` for non-reactive lookups where possible, or use atomic selectors.
