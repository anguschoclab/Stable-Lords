## 2025-02-09 - Zustand `useShallow` array mapping performance
**Learning:** Selecting a deeply nested array of objects (like `s.roster`) directly from Zustand without memoizing specific properties causes components to unnecessarily re-render whenever unrelated properties of any object within the array change. Using `useShallow` with an array mapping to objects (e.g. `.map(w => ({ id: w.id, name: w.name }))`) fails the shallow equality check because it creates a new object reference on every state change, defeating the purpose.
**Action:** Always map complex objects to an array of primitive values using `flatMap` (e.g., `s.roster.flatMap((w) => [w.id, w.name])`) with `useShallow`, and reconstruct the required objects inside a separate `useMemo` block based on those extracted primitives.
