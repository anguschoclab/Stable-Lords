### 1b. Module responsibility census — NEW `scripts/srp-census.mjs`

Validated need: size alone misclassifies. `narrateEvents/handlers.ts` (562)
is a uniform ~20-handler dispatch table — already decomposed;
`stateInvariants.ts` (454) is cohesive per-check validators + 2 entry
points; `recruitmentWorker.ts` (455) is a cohesive pipeline worker;
`notable.ts` (714) is a homogeneous `Record<string, TraitDef>` data table;
`arenaFit.ts` (467) is borderline — one domain, mild phase mixing. The
census must therefore flag mixed-responsibility **signals**, not bytes:

- heterogeneous export clusters (unrelated export families in one module)
- multi-domain imports (a file reaching across several engine domains)
- fan-out breadth (many distinct callees)
- section-banner blocks (`// ─── X ───` partitions marking de-facto modules)
- god-hooks/god-components doing fetch + derive + render in one unit

Classification requires **reading**, not just metrics — the census emits
candidates with their signal profile; each is classified-by-reading into
the FINDINGS verdict tables.

## Phase 4 — Harmonize-not-delete consolidation

Per §D cluster, one at a time:

1. Variation-point diff → EXEMPT/DEBT verdict recorded in FINDINGS.
2. DEBT: extract a shared parameterized utility into the correct domain —
   `src/lib`, `src/components/ui`, `src/engine/<domain>/`, or
   `src/test/_fixtures/` for test dedup (factories.ts is the enforced
   harmonization target for local factories).
3. Safe-codemod repoint: build the explicit keep-set (identifiers, object
   keys, enum/comparison values, imports, numeric separators — functional
   tokens never transformed), run scripted, verify with
   type-check/lint/test, and **revert-and-redo** on any corruption — never
   forward-patch damage.
4. Remove the pair from its ledger set and ratchet the baseline down in
   the same commit.

One cluster per commit; deletes never mixed with moves; characterization
tests green before **and** after.

## Phase 5 — Unique-code preservation protocol

  code, and asserted by its preservation spec.
- `orphan-scan` stays 0; the knip export delta is the preserved-logic
