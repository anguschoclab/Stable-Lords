## The new `docsLayout` guard — what it must pin

Per the `guard-ratchet` skill pattern (scanner + allowlist + LIVE_RATCHET disposition): docs-root `.md` allowlist (`INDEX.md`, `MEGAPLAN_BACKLOG.md`, `MEGAPLAN_V<N>_*`); repo-root `.md` ⊆ `{README.md, AGENTS.md}` (blocks doc drift back to root); approved docs dirs (`design|engineering|reports|manual|archive`); archive subdirs (`megaplans|audits|summaries|superpowers`); kebab ratchet on non-archive docs; relative-link integrity (non-archive docs + root meta); INDEX freshness (every non-archive doc linked).
